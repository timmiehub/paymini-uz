# Что сделать тебе (по шагам)

Сервер уже можно крутить локально **без ключей** (демо в памяти).

## Сейчас — проверить демо (уже работает)

1. Открой в Chrome: http://localhost:5173  
2. Создай бизнес → «Пока демо-режим» → **Принять оплату** → введи сумму → **Показать QR**.  
3. Скопируй ссылку под QR (или открой её во второй вкладке).  
4. Нажми **Оплатить** → статус «Оплачено», в истории платежей появится запись.

## Потом — живой Telegram-бот

1. Открой Telegram → найди **@BotFather**.  
2. Напиши `/newbot` → придумай имя и username (например `PayMiniUzBot`).  
3. Скопируй токен (длинная строка).  
4. Вставь его в файл `C:\Users\user\paymini-uz\bot\.env` вместо `REPLACE_ME`:  
   `BOT_TOKEN=вставь_токен_сюда`  
5. В BotFather: `/mybots` → свой бот → **Bot Settings** → **Menu Button** → URL: `http://localhost:5173`  
   (для телефона с улицы нужен ngrok — скажи, подниму).  
6. Перезапусти бота (скажи мне «токен вставил» — перезапущу сам).

## Потом — постоянная база (Supabase)

1. Зайди на https://supabase.com → Sign in → **New project**.  
2. После создания: **SQL Editor** → New query → вставь весь файл  
   `C:\Users\user\paymini-uz\supabase\schema.sql` → **Run**.  
3. **Project Settings → API**: скопируй  
   - Project URL  
   - `anon` `public` key  
   - `service_role` key (секретный, только в bot/.env)  
4. Напиши мне «supabase готов» + три значения (или вставь сам в `.env`) — переключу с локальной памяти на базу.

## Потом — реальный Payme

1. Кабинет https://business.payme.uz  
2. Создай кассу → Merchant ID + ключ API.  
3. Callback URL: адрес твоего сервера `/payme` (после деплоя).  
4. В приложении: **Инструкция Payme** → вставь Merchant ID.  
5. В `bot/.env`: `PAYME_DEMO=0`, `PAYME_MERCHANT_ID=...`, `PAYME_MERCHANT_KEY=...`

---

**Итог после шага «Сейчас»:** видишь QR и демо-оплату в браузере.  
**Итог после бота:** то же из Telegram.  
**Итог после Supabase+Payme:** настоящие платежи на карту мерчанта.
