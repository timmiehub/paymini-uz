# PayMini UZ — QR-оплата у стойки

Полный план: `.cursor/plans/uz_booking_from_telegram_ed868a70.plan.md`

## Продукт одной фразой

Владелец по инструкции подключает Payme → показывает QR в приложении → клиент сканирует → платит за 30 секунд.

## Не для кого

Не CRM, не супер-апп. Только **быстрый безнал** в Telegram / по ссылке.

## Сценарии

1. **Живая оплата** — QR на экране владельца (сумма / оффер) → сканирование → Payme
2. **Ссылка в чат** — то же самое без QR
3. Позже: каталог, запись с предоплатой

## Онбординг владельца

1. Создать бизнес в Mini App
2. Пошагово подключить Payme (Merchant ID + ключ по нашей инструкции)
3. Готово: экран «Принять оплату» + QR

## MVP

- Инструкция Payme внутри приложения
- Экран живой оплаты + QR
- Клиентский pay-link
- Demo-режим без ключей (для теста)
